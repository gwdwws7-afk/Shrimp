# 无双设计 Skill - QA 验证表

## 快速验证（每关 1 轮）
- 记录 KPM、连段平均时长、破防频率、击飞频率
- 记录 3 次最大连段时长
- 记录 1 次最常见失败原因

## 目标区间
- KPM：90–150
- 连段平均时长：20–35s
- 破防频率：15–25s
- 击飞频率：2–4s
- 喘息时间：5–8s

## 诊断与修复
- 爽感不足 → 提高基础怪比例 / 提升击中反馈密度
- 连段易断 → 降低远程/控制比例 / 增加容错
- 事件压迫过强 → 降低事件密度 / 增加喘息
- Boss 疲劳 → 增加破防窗口与爆发阶段
