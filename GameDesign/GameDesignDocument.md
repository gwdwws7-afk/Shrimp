## 3. 游戏核心概念

### 3.1 游戏名称
**中文**: 深渊猎手：异种肃清  
**英文**: Abyss Hunter: Xenocide

### 3.2 世界观设定（完整版）

**时代背景**: 公元2147年，人类启动深海能源计划“深蓝计划”，在马里亚纳裂谷深处进行高压钻探。钻探触发“裂潮门”开启，沉睡于深渊的异种生物机械文明被唤醒。

**异种文明（潮墓群）**:
- 形态: 生物与机械融合体，具备自我修复、共振通讯与群体进化能力。
- 组织: 以“母巢核心体”为中枢，通过“静潮圣所”传导群体意志。
- 目的: 夺回被深海封印的“深渊核”，驱动扩张与改造海床。

**人类阵营（深渊前线局）**:
- 组织: 深海前线局(PTA)负责清剿与情报回收。
- 技术: 逆向异种生物科技与深潜动力装甲。
- 战术: 孤军深入、点状据点清剿、短时窗口破防。

**关键资源**:
- 深渊珍珠: 异种能源结晶，可用于武器与天赋升级。
- 声潮共振: 异种群体通信网络，需通过据点破坏节点断链。

**主角定位**:
- 深渊猎手（代号: Starman）是前线局最强单兵，擅长高速斩击与群体压制。
- 任务: 回收失事研究站数据，切断共振网络，摧毁母巢核心。

**主线矛盾**:
人类必须在“裂潮门”完全开启前摧毁母巢核心，否则沿海城市将被异种改造为孵化巢床。

### 3.3 核心玩法循环
```
进入关卡 → 割草战斗 → 收集资源 → 升级能力 → 挑战Boss → 解锁新区域
    ↑                                                    ↓
    └──────────────── 重复强化 ────────────────────────────┘
```

### 3.4 核心体验支柱

| 支柱 | 描述 | 实现方式 |
|------|------|----------|
| **爽快感** | 一刀下去敌人成片倒下 | 大范围攻击、夸张击退 |
| **成长感** | 角色越来越强大 | 技能树、装备升级 |
| **新鲜感** | 每次游戏都有新敌人 | AI实时生成变异模型 |
| **挑战性** | Boss战需要技巧 | 阶段式设计、弱点机制 |

```
敌人群体管理器
├── 对象池: 预生成200个敌人实体
├── 分区管理: 将地图划分为10x10网格
├── LOD AI:
│   ├── 近距离(<20m): 完整AI
│   ├── 中距离(20-50m): 简化AI
│   └── 远距离(>50m): 仅位置同步
├── 群体寻路: Flow Field算法
└── 同步机制: Burst编译 + Job System
```

**性能目标**:
- 同屏敌人: 50+ @ 60fps
- 敌人总数: 200 (对象池)
- 内存占用: < 500MB

## 6. AI生成内容管线

### 6.1 角色生成流程

```
阶段1: 概念生成
├── 输入: 敌人类型 + 关卡主题
└── 输出: 文字描述 + 关键词

阶段2: 3D模型生成
├── 工具: Meshy AI / Tripo3D / CSM
├── 参数:
│   ├── 多边形数: 5000-8000
│   ├── 贴图: 2K PBR (Albedo/Normal/Metallic/Roughness)
│   └── 格式: FBX
└── 输出: 基础模型

阶段3: 自动绑定
├── 工具: Mixamo / AccuRIG / Unity Animation Rigging
├── 骨骼数: 30-40根
└── 输出: 绑定好的模型

阶段4: 动画重定向
├── 源动画: Mixamo动作库(200+动作)
├── 目标: 生成的模型骨骼
└── 工具: Unity Animation Rigging

阶段5: 游戏集成
├── 导入Unity
├── 材质球设置
├── 预制体创建
└── 游戏参数配置
```

### 7.6 Boss战斗脚本模板（统一规范）

**目标**: 每个Boss 3-4 技能，2阶段，必含弱点/破防窗口。

**设计规范**
- 阶段1: 2-3个基础技能 + 1个节奏技能
- 阶段2: 2-3个强化技能 + 1个破防相关技能
- 破防窗口: 触发后 3-5 秒可打出高伤害
- 破防触发条件: 弱点破坏 / 特定技能中断 / 破韧槽清空

**Boss脚本结构建议**
```csharp
public class BossControllerBase : MonoBehaviour
{
    public enum Phase { Phase1, Phase2 }

    [Header("Phase")]
    public Phase currentPhase = Phase.Phase1;
    public float phase2HealthThreshold = 0.5f;

    [Header("Break Window")]
    public bool breakable = true;
    public float breakWindowDuration = 4f;
    public float breakCooldown = 12f;
    public float staggerMax = 100f;
    public float staggerCurrent = 0f;

    [Header("Skills")]
    public List<BossSkill> phase1Skills = new List<BossSkill>();
    public List<BossSkill> phase2Skills = new List<BossSkill>();

    [Header("Weak Point")]
    public Transform weakPoint;
    public float weakPointMultiplier = 2.0f;

    public void TickAI()
    {
        if (currentPhase == Phase.Phase1 && HealthPercent() <= phase2HealthThreshold)
        {
            EnterPhase2();
        }

        if (IsBreakWindowActive())
        {
            // Optional: slow time or lock to defensive behavior
            return;
        }

        BossSkill next = SelectSkill();
        if (next != null)
        {
            ExecuteSkill(next);
        }
    }

    public void ApplyStagger(float amount)
    {
        if (!breakable || IsBreakWindowActive()) return;
        staggerCurrent = Mathf.Min(staggerMax, staggerCurrent + amount);
        if (staggerCurrent >= staggerMax)
        {
            TriggerBreakWindow();
        }
    }

    private BossSkill SelectSkill()
    {
        // Weighted random with cooldown checks
        return null;
    }
}

[System.Serializable]
public class BossSkill
{
    public string id;
    public string name;
    public float cooldown = 6f;
    public float windup = 0.5f;
    public float active = 0.6f;
    public float recovery = 0.8f;
    public float damageMultiplier = 1.0f;
    public bool canTriggerBreak = false;
}
```

**破防窗口规范**
- 触发时播放破防提示与显著特效
- Boss进入短暂硬直/暴露核心
- 期间受到伤害提高 50-100%

**技能结构建议**
- 技能A: 控场 (拉扯/击退/区域限制)
- 技能B: 输出 (直线/扇形/大范围)
- 技能C: 机制 (召唤/护盾/弱点)
- 技能D: 阶段专属爆发
