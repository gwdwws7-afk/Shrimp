# 美术资产功能优先级矩阵（P0，Shrimp）

更新时间: 2026-03-24  
适用模块: 美术资产（对应系统卡 `27`）  
目标: 方法论分数从 `56` 提升到 `>=75`（先达可推进线）

## 1. 现状与策略

- 当前问题:
  - 资产总量与一致性不足，尤其 Boss/UI/VFX/品牌素材。
- 执行策略:
  - 先做“功能可读资产”补齐，再做风格强化。
  - 以玩法可读性作为优先级排序原则。

## 2. 优先级定义

- `P0-Blocker`:
  - 缺失会直接影响可玩性或读招能力。
- `P0-High`:
  - 缺失会显著降低体感与信息可读。
- `P1`:
  - 提升体验与一致性，但不阻塞主流程。
- `P2`:
  - 发布风格强化与品牌深化项。

## 3. 功能优先级矩阵

| 类别 | 资产项 | 优先级 | 验收口径 |
|---|---|---|---|
| Boss | Boss 轮廓与弱点可读材质 | P0-Blocker | 关键弱点在战斗中可一眼识别 |
| Boss | 阶段切换视觉状态差异 | P0-High | 阶段转换不靠文案也能识别 |
| UI | 核心 HUD 图标（血/耐/技能/任务） | P0-Blocker | 主流程无占位图或错义图标 |
| UI | 手柄/键鼠提示图标集 | P0-High | 设备切换提示图标一致 |
| VFX | 命中/受击/破防/终结关键特效 | P0-Blocker | 关键战斗反馈全覆盖 |
| 关卡 | 据点核心/占点范围功能材质 | P0-Blocker | 占点边界与状态可读 |
| 关卡 | 事件区域标记（追击/保护） | P0-High | 事件目标与危险区可区分 |
| 敌人 | 高威胁敌种识别特征强化 | P0-High | 精英/控制/自爆易识别 |
| 品牌 | Steam 商店必需素材集 | P1 | 上线所需规格齐套 |
| 风格 | 场景装饰与氛围细化 | P2 | 不影响功能读图 |

## 4. P0 交付范围（本轮必须）

1. Boss 关键读招资产（轮廓/弱点/阶段差异）  
2. HUD 与提示图标可读资产  
3. 关键战斗与据点事件功能性 VFX  
4. 据点交互对象与事件区域功能材质

## 5. 验收标准（量化）

- 指标 1:
  - P0-Blocker 项目完成率 `>=95%`（目标 100%）。
- 指标 2:
  - “关键读招资产缺失”问题数降为 0。
- 指标 3:
  - 功能资产覆盖后，系统卡中“反馈可读性与教学”维度至少提升 2 分。

## 8. 执行顺序（建议）

1. 先清 `P0-Blocker`（Boss/UI/关键VFX/据点交互）。  
2. 再补 `P0-High`（敌种识别与设备图标一致性）。  
3. 最后进入 `P1/P2` 的品牌与风格强化。
