# 系统设计卡：战斗系统（Shrimp）

更新时间: 2026-03-24
版本: v0.1（文档优化轮）
Owner: Design/Combat
关联 DDR-ID: `DDR-2026-03-24-15`

## 1) 设计对象

- 该系统服务的玩家行为:
  - 在群战中完成连击、重击、技能衔接与资源管理。
- 系统边界（与其他系统接口）:
  - 上游: 输入、角色状态。
  - 下游: 伤害结算、连击层级、耐力消耗、技能收益、反馈系统。

## 2) 玩家核心幻想

- 玩家在该系统中“想实现什么”:
  - 我能打出连续高压操作，并通过正确节奏获得明显收益。

## 3) 30 秒到 3 分钟核心循环

- 30 秒循环:
  - 普攻起连 -> 重击或技能插入 -> 规避反击 -> 连段续上。
- 3 分钟循环:
  - 连击收益积累 -> 资源压力管理 -> 爆发窗口收割。

## 4) 关键规则与约束

- 规则 1: 连击收益必须与操作风险成正比。
- 规则 2: 耐力限制需防止无限攻防循环。
- 规则 3: 技能收益曲线应形成明确角色分工。
- 关键约束:
  - 低帧率下时序应保持单次结算一致。
  - 被打断、连招切换、边界行为可回归验证。

## 5) 决策点与风险回报

- 主要决策点: 连击延续还是保留资源防守反打。
- 失败代价: 断连、力竭、被反打失去节奏。
- 成功收益: 更高输出、更快清场、更稳生存。

## 6) 反馈与可读性策略

- 视觉反馈: 命中、暴击、破防、终结状态层次化。
- 音频反馈: 连击层级与关键命中差异化提示。
- UI 提示: 连击计数、耐力状态、技能可用状态明确。
- 失败纠偏: 显示断连主因（资源不足/被打断/时机错误）。

## 7) 学习曲线与失败学习点

- 入门: 普攻节奏与基础闪避。
- 首次失败: 理解耐力与连击的平衡关系。
- 进阶: 学会爆发窗口留技能与控风险。

## 8) 核心参数区间（最小/推荐/最大）

- 连击重置时间（秒）: `0.8 / 1.1 / 1.5`
- 重击耐力消耗（点）: `18 / 22 / 28`
- 闪避耐力消耗（点）: `12 / 17 / 24`
- 耐力恢复（点/秒）: `10 / 14 / 18`

## 9) 验收标准（量化）

- 指标 1: Round1 战斗回归关键边界用例全通过。
- 指标 2: 低帧率时序回归无重复结算异常。
- 指标 3: 连击/耐力/技能收益曲线有参数化提案与证据。
