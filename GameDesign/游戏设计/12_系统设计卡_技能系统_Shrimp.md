# 系统设计卡：技能系统（Shrimp）

更新时间: 2026-03-24
版本: v0.1（文档优化轮）
Owner: Design/Combat/Skill
关联 DDR-ID: `DDR-2026-03-24-06`

## 1) 设计对象

- 该系统服务的玩家行为:
  - 在普攻与重击主链上，通过 6 个主动技能形成“位移、控场、爆发、保命”的战术选择。
  - 在连击与耐力压力下做技能时机管理，而不是无脑轮放。
- 系统边界（与其他系统接口）:
  - 上游: 输入系统、耐力系统、冷却系统、角色状态机。
  - 下游: 伤害结算、控制效果、UI 技能栏、音画反馈系统。

## 2) 玩家核心幻想

- 玩家在该系统中“想实现什么”:
  - 我能用技能组合改变战局节奏，在群战中打出“聚怪-破防-收割”的高光链。

## 3) 30 秒到 3 分钟核心循环

- 30 秒循环:
  - 判断敌群形态 -> 释放一个关键技能打出位移或控场 -> 用普攻延续连击并等待窗口。
- 3 分钟循环:
  - 多技能轮转（位移/控场/爆发）-> 触发连击收益与资源回转 -> 打出一次阶段性峰值。

## 4) 关键规则与约束

- 规则 1:
  - 技能分工必须明确（输出、控场、位移、生存），避免功能重叠导致决策无意义。
- 规则 2:
  - 每个技能必须定义“前摇提示 -> 生效判定 -> 收招风险”，可读且可预判。
- 规则 3:
  - 技能收益需受 CD、耐力与连击状态共同约束，避免单一维度失控。
- 关键约束（性能/输入/资源/时序）:
  - 本轮不改核心逻辑，只补齐策划规范与资源化要求。
  - 与统一输入层和技能边界回归门禁保持一致。

## 5) 决策点与风险回报

- 主要决策点:
  - 技能是否用于保命/控场，还是留给爆发窗口。
  - 是否冒险在高压下读条释放高收益技能。
- 失败代价:
  - 错误时机导致技能空放、连击中断、耐力见底。
- 成功收益:
  - 通过正确轮转显著提升清场效率与生存稳定性。

## 6) 反馈与可读性策略

- 视觉反馈:
  - 技能起手、命中区、控制生效、终止状态必须显著可辨。
- 音频反馈:
  - 释放、命中、冷却完成三类提示要有层级差异。
- UI 提示:
  - 技能栏需明确显示 CD、可释放状态、资源不足原因。
- 失败后纠偏提示:
  - 在训练或失败复盘中提示“空放原因”（超距、资源不足、被打断）。

## 7) 学习曲线与失败学习点

- 入门教学节点:
  - 前两关建立“位移技能保命、控场技能开节奏”的基础认知。
- 第一次失败学习点:
  - 玩家意识到“CD 可用不等于应立即释放”，需看战场窗口。
- 中后期进阶点:
  - 学会围绕 Boss/精英破防窗口做技能保留与爆发联动。

## 8) 核心参数区间（最小/推荐/最大）

- 小技能冷却（秒）: `6 / 8-15 / 20`
- 终极技能冷却（秒）: `45 / 60 / 75`
- 技能耐力消耗（点）: `0 / 15-30 / 40`
- 控场技能有效时长（秒）: `1 / 2 / 3.5`

## 9) 验收标准（量化）

- 指标 1（技能可读性）:
  - 6 个技能均具备“起手提示/生效反馈/结束反馈”三段式定义与资源位映射。
- 指标 2（战术差异）:
  - 至少形成 3 种可复现技能轮转策略（清场向、保命向、爆发向）。
- 指标 3（边界稳定性）:
  - 技能边界专项回归无阻塞失败，且关键异常有可追溯证据。
