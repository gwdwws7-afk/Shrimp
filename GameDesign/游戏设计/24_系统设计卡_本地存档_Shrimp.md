# 系统设计卡：本地存档（Shrimp）

更新时间: 2026-03-24
版本: v0.1（文档优化轮）
Owner: Design/Save
关联 DDR-ID: `DDR-2026-03-24-18`

## 1) 设计对象

- 该系统服务的玩家行为:
  - 在跨会话游玩中稳定保留进度、设置与成长状态。
- 系统边界（与其他系统接口）:
  - 上游: 任务、成长、设置、本地化语言状态。
  - 下游: 本地文件读写、云桥接同步、异常恢复。

## 2) 玩家核心幻想

- 玩家在该系统中“想实现什么”:
  - 退出再进入后我的状态是连续且可信的。

## 3) 30 秒到 3 分钟核心循环

- 30 秒循环:
  - 状态变更 -> 触发保存 -> 读取验证。
- 3 分钟循环:
  - 多系统状态写入 -> 下次会话恢复 -> 与云策略一致。

## 4) 关键规则与约束

- 规则 1: 保存与恢复必须保证关键字段一致性。
- 规则 2: 设置（含语言）必须持久化，不受场景切换影响。
- 规则 3: 本地与云冲突需有稳定优先级分支。
- 关键约束:
  - 不允许“扣费/进度变更后未持久化”。
  - 异常场景需有回退路径。

## 5) 决策点与风险回报

- 主要决策点: 保存时机、冲突优先级、恢复容错策略。
- 失败代价: 进度丢失或状态错位，直接破坏用户信任。
- 成功收益: 会话连续性强，发布稳定性提升。

## 6) 反馈与可读性策略

- 视觉反馈: 保存成功/冲突处理结果可见。
- 音频反馈: 关键确认可选轻提示。
- UI 提示: 设置保存与应用状态明确。
- 失败纠偏: 保存失败时给出可执行重试/回退提示。

## 7) 学习曲线与失败学习点

- 入门: 默认自动保存无感知。
- 首次失败: 冲突或写入失败时可理解处理逻辑。
- 进阶: 与云同步策略协同使用。

## 8) 核心参数区间（最小/推荐/最大）

- 关键字段恢复一致性（%）: `95 / 100 / 100`
- 设置持久化成功率（%）: `95 / 100 / 100`
- 云冲突分支覆盖（条）: `2 / 3 / 3`

## 9) 验收标准（量化）

- 指标 1: 设置（含语言）保存与恢复回归通过。
- 指标 2: 云桥接 pull/push/newest 分支回归通过。
- 指标 3: 全量门禁中存档相关路径无阻塞失败。
