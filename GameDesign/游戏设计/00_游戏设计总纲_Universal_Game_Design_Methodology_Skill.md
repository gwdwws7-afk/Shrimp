# 游戏设计总纲 / Universal Game Design Methodology

## Skill 目标
让 AI 能够以“总纲”视角分析、总结、评审与辅助设计单机游戏系统，并输出可落地的方法论结论。

## 适用场景
适用于所有单机游戏分析、设计评审、竞品拆解、原型讨论与 AI 设计辅助。

## 核心概念
核心幻想、核心循环、决策结构、反馈结构、学习曲线、难度来源、内容扩展、设计边界

## 标准分析流程
1. 明确目标体验与玩家幻想。
2. 识别该主题下最关键的系统与约束。
3. 按该方法论视角拆解循环、反馈、节奏与风险。
4. 指出强项、失配点、边界条件与优化机会。
5. 以结构化模板输出结论，避免只给感性评价。

### 该 Skill 的推荐流程
先确认玩家幻想；再拆 30 秒到 3 分钟循环；识别决策负荷；检查反馈与教学；验证难度曲线；总结设计支柱。

## 标准输出模板
- 设计对象：
- 玩家核心幻想：
- 核心循环：
- 关键系统与规则：
- 决策点与风险回报：
- 反馈与可读性：
- 学习曲线与难度来源：
- 当前设计亮点：
- 当前设计问题：
- 可执行优化建议：

### 本 Skill 的重点输出
输出统一设计分析骨架，作为后续各品类 skill 的上位接口。

## 检查清单
- 是否明确玩家在这里追求的体验？
- 是否识别了关键规则与关键反馈？
- 是否能说明玩家为什么会这样行动？
- 是否指出了节奏、难度或信息层的主要问题？
- 建议是否能落到系统、关卡、数值或内容生产上？

## 常见误区
- 把 feature 列表误当方法论；只谈创意不谈循环；只谈数值不谈体验。
- 输出只有术语堆砌，没有结合具体对象。
- 没有给出边界条件与适用前提。

## AI 使用准则
1. 先给结构，再给观点。
2. 先讲因果，再讲好坏。
3. 避免把个人喜好写成普适结论。
4. 结论必须能回到玩家行为和系统规则。
5. 当信息不足时，明确假设条件。

## 一句话记忆
任何品类都先回到幻想、循环、决策、反馈四件事。
